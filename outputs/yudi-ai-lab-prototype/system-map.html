SYSTEM LOGIC

不是三个作品，是一条 AI 产品工作流链路

这个版本把页面重心放在关系上：AI 不只是生成内容，它可以进入想法、设计、决策三个连续环节，并在每个环节形成不同的产品机制。

01 / idea formation

从灵感到可讨论材料

Idea Storm Lab 处理的是早期创业团队的想法收集、LLM 分析、商业建模和方向归纳。

02 / design memory

从对话到可恢复协作

Design Harness 处理的是 AI 参与设计时的状态、用户确认、项目记忆和交付封存。

03 / decision runtime

从策略到可解释决策

ARCOS 处理的是企业级调度场景中，有限资源下如何最小化整体违约风险。

DESIGN MEMOS

方法论项目，用设计备忘录表达

Design Harness 和 ARCOS 不强行放截图。它们更像设计思想和策略系统，应该用备忘录、原则和模型来呈现。

memo / design harness

AI 设计协作需要状态、批准和记忆

Design Harness 关注的是让 AI 在产品设计过程中拥有可恢复上下文、明确确认点、可审计决策和可继承项目记忆。

  • Thread 是临时工作现场，Work Item 才是可验收任务。
  • 视觉方向、配色、排版、设计禁区和关闭都需要用户确认。
  • 项目记忆沉淀为可读文件，而不是只存在对话上下文里。
memo / arcos

调度是有限资源下的风险治理

ARCOS 将调度问题从“派给谁”拆解为工单风险、资源能力、时间压力、工作难度、负载均衡和可解释验证。

  • 调度目标不是每张工单都不逾期，而是最小化调度域整体违约风险。
  • 四象限处理时间紧迫度与综合风险等级，WHL 环层修正工作难度。
  • WG1-WG8 将在岗、位置、负载、经验、效率、稳定和技能变成可解释评分。
